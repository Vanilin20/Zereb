# Жереб

Браузерний симулятор життя: народжуєшся випадковою людиною з 8 мільярдів (країна зважена за реальною кількістю народжень) і проживаєш її долю — освіта, робота, хобі, бізнес, еміграція, родина.

**Грати:** https://vanilin20.github.io/Zereb/

Статичний сайт без збірки: `index.html`, `style.css`, `js/`. Дані про країни приблизні (ООН, Світовий банк, ЮНІСЕФ).
